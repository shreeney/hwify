Simple Python script to make hw-probe data easier to read for FreeBSD laptop project testing. The Makefile runs hardware probe, then runs the python script to make the data easier to read. This tool was built for FreeBSD but works on Linux, however the tarball generated by hw-probe is different.

NOTE: I do development of the script here, but the script itself is deployed for use at the [FreeBSD Foundation's laptop testing github](https://github.com/FreeBSDFoundation/freebsd-laptop-testing). If you want to try the script out you should go there
