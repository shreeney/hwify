Simple Python script to make hw-probe data easier to read for FreeBSD laptop project testing. The Makefile runs hardware probe, then runs the python script to make the data easier to read. This tool was built for FreeBSD. The parser parses the human-readable output into HTML table rows for display in a static website. 
NOTE: I did initial development here, but the script itself is now deployed for use at the [FreeBSD Foundation's laptop testing github](https://github.com/FreeBSDFoundation/freebsd-laptop-testing). The workflow and everything is there so consider this repo unmaintained
